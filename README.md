## ⚙️ Requirements

- Python 3.10 or later
- A Python-compatible code editor, such as Visual Studio Code
- Required Python libraries for the relevant programs

Install the main data analysis libraries:

```bash
python -m pip install numpy pandas matplotlib
```

Install Django for the web development practicals:

```bash
python -m pip install django
```

Tkinter is included with many standard Python installations. On some systems, it may need to be installed separately.

## 🚀 How to Run the Programs

1. Clone or download this repository.
2. Open the repository folder in Visual Studio Code or a terminal.
3. Navigate to the folder containing the Python program you want to execute.
4. Run the program using Python.

Example:

```bash
python program.py
```

For Django programs, navigate to the folder containing `manage.py` and run:

```bash
python manage.py migrate
python manage.py runserver
```

Then open `http://127.0.0.1:8000/` in your browser.

**Note:** Replace `program.py` with the actual Python filename. Some exercises may require additional setup or dependencies.
