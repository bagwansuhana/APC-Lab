# Django Python Practicals

A collection of beginner-to-intermediate Python programs developed using the Django web framework.

## Programs Included

1. Hello World using Django
2. Display Student Details
3. HTML Templates and Dynamic Data
4. URL Routing and Multiple Pages
5. Student Registration Form
6. Login Form with Validation
7. Email and Phone Validation using Regular Expressions
8. Student Database Management
9. Search Student Records
10. Update and Delete Student Records

## Technologies Used

- Python
- Django
- HTML
- SQLite
- Regular Expressions

## Installation

1. Install Python.
2. Clone or download this repository.
3. Open a terminal in the required program folder.
4. Install dependencies:

   `python -m pip install -r requirements.txt`

5. Run database migrations if required:

   `python manage.py migrate`

6. Start the development server:

   `python manage.py runserver`

7. Open `http://127.0.0.1:8000/` in your browser.

## Learning Objectives

- Understand Django project and app structure.
- Create views and configure URL routing.
- Use HTML templates and forms.
- Validate user input.
- Perform database CRUD operations.
- Search database records using Django ORM.

## Note

These programs are intended for educational and practical examination purposes. The demonstration login uses fixed credentials and is not intended for production use.
